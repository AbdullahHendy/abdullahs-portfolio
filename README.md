# Abdullah's Portfolio

 My personal portfolio showcasing a bit about my technical background, experiences, projects, and skills. Built with Astro, React (edited Aceternity UI Components), and Tailwind CSS with attention to mobile user experience too!

> **NOTE**: Not tested on large displays. Fully responsive design for medium (md) and small (sm) devices only.
>

Feel free to **fork 🔱**

## 🚀 Run Locally

To run locally and expose on the network, i.e, test on different devices on the network:

You need to have [**node/npm**](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) to run it!

```bash
git clone https://github.com/AbdullahHendy/abdullahs-portfolio.git
cd abdullahs-portfolio/
npm run dev -- --host
```
